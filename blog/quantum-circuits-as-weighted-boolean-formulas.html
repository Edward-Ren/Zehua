1. Motivation：为什么把 quantum circuit 写成 logic？

一个 nn-qubit pure state 可以写成：

|ψ⟩=∑b∈{0,1}nαb|b⟩,∑b|αb|2=1. |\psi\rangle=\sum_{b\in\{0,1\}^n}\alpha_b|b\rangle, \qquad \sum_b|\alpha_b|^2=1.

这里 bb 是一个长度为 nn 的 bit string，αb\alpha_b 是对应的 amplitude。直接存储这个 state vector，一般需要 2n2^n 个 complex numbers。Circuit 本身可能只是一个不长的 gate sequence，但它作用的空间已经很大了。

Classical simulation 要从这个紧凑的 circuit description 算出 quantum behaviour。Weak simulation 是按测量分布产生 outcomes；strong simulation 则计算指定的 amplitude 或 measurement probability。这里关注后者。

Simulation paper 的 Introduction 从 strong simulation 与 #P counting problems 的联系出发，提出了一个具体问题：能不能把 quantum circuit 的计算交给 weighted model counter？Complexity 上有关联还不够，实际使用时还需要一个尺寸可控、能够保留 quantum semantics 的 encoding。

先把问题拆开：basis component 是哪一个，以及它贡献了多少。这两件事分别交给 Boolean constraints 和 numerical weights。后面再看同样的表示怎样用于 simulation、equivalence checking，最后用于 synthesis。

2. 从 Basis State 到 Weighted Model Counting

2.1 Boolean assignment 能表示什么？

从最直接的 computational basis 开始。一个 qubit 的 basis state 只需要一个 Boolean variable：

|0⟩↔q=0↔¬q,|1⟩↔q=1↔q. |0\rangle\longleftrightarrow q=0\longleftrightarrow\neg q, \qquad |1\rangle\longleftrightarrow q=1\longleftrightarrow q.

两个 qubits 同理。例如按从左到右的 qubit 顺序：

|10⟩↔(q0,q1)=(1,0)↔q0∧¬q1. |10\rangle\longleftrightarrow(q_0,q_1)=(1,0) \longleftrightarrow q_0\land\neg q_1.

但 Boolean assignment 只告诉我们是哪一个 basis component。考虑：

|+⟩=|0⟩+|1⟩2,|−⟩=|0⟩−|1⟩2. |+\rangle=\frac{|0\rangle+|1\rangle}{\sqrt2}, \qquad |-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt2}.

两者都包含 |0⟩|0\rangle 和 |1⟩|1\rangle。只保留这两个 assignments，就丢掉了它们的区别。还需要保留 amplitude，尤其是第二个 component 的符号。

因此，Boolean structure 表示允许哪些 components 或 transitions；weights 表示这些 components 对所求 quantum quantity 的数值贡献。一般的 CB amplitudes 可以是 complex，所以不只是正负号的问题。这是 synthesis paper §2.3 中 computational basis encoding 的出发点。

2.2 为什么需要 WMC？

普通 #SAT 对每个 satisfying assignment 都加 11：

#SAT⁡(F)=∑ω⊨F1. \#\operatorname{SAT}(F)=\sum_{\omega\models F}1.

Weighted Model Counting 则给每个 literal 一个 weight。把完整 assignment ω\omega 看成它取真的 literals 的集合，定义：

W(ω)=∏ℓ∈ωw(ℓ),WMC⁡w(F)=∑ω⊨FW(ω). W(\omega)=\prod_{\ell\in\omega}w(\ell), \qquad \operatorname{WMC}_w(F)=\sum_{\omega\models F}W(\omega).

也就是先在一个 assignment 内做乘法，再在不同 assignments 之间做加法。没有特殊说明时，w(v)=w(¬v)=1w(v)=w(\neg v)=1；这表示这个 variable 本身不改变数值贡献，而不是给它一个均匀概率分布。（Simulation paper §2.3；synthesis paper §2.2。）

Quantum contributions 不会每次都等于 11。有些 contribution 可以相消，例如：

12+(−12)=0. \frac12+\left(-\frac12\right)=0.

如果只数 satisfying assignments，这里会得到 22；如果保留 weights，就可以得到 00。后面两个 Hadamard gates 的例子会让这个 cancellation 具体发生。

这里加起来的是 amplitudes 或其他代数贡献。Physical measurement probability 仍然是非负实数。WMC 中允许 negative 或 complex weights，并不意味着 quantum probability 可以为负或为 complex。

3. Gate：一个 Weighted Transition Relation

一个 gate 的 matrix element 描述 input basis state 到 output basis state 的 contribution。因此可以把 gate 写成一个 weighted Boolean transition relation：

FG(𝐪,𝐪′,𝐮). F_G(\mathbf q,\mathbf q',\mathbf u).

𝐪\mathbf q 表示 gate 前的 basis label，𝐪′\mathbf q' 表示 gate 后的 label；𝐮\mathbf u 是用于挂接 weights 的 auxiliary variables。这里的单个 label 并不是整个 superposition，整个 state 要由许多 weighted assignments 一起表示。

例如 Hadamard gate：

H=12(111−1). H=\frac1{\sqrt2} \begin{pmatrix}1&1\\1&-1\end{pmatrix}.

按 column 为 input、row 为 output，可以直接读出：

Input Output Transition amplitude
00 00 1/21/\sqrt2
00 11 1/21/\sqrt2
11 00 1/21/\sqrt2
11 11 −1/2-1/\sqrt2

四种 transitions 都允许，只有最后一种需要负号。Synthesis paper Table 2 用两个 auxiliaries h,rh,r 表达这件事：

FH(q,q′,h,r)=h∧(r↔(q∧q′)), F_H(q,q',h,r)=h\land\bigl(r\leftrightarrow(q\land q')\bigr),
w(h)=12,w(r)=−1,w(¬r)=1. w(h)=\frac1{\sqrt2},\qquad w(r)=-1,\qquad w(\neg r)=1.

强制 hh 为真，就让每个 transition 都乘上 1/21/\sqrt2；rr 恰好在 q=q′=1q=q'=1 时为真，再引入一个负号。给定 input/output 后，这两个 auxiliaries 的取值也确定了，不会额外制造重复贡献。

这就是把 gate matrix 写成 weighted transition relation。其他 gates 也按对应的 matrix elements 编码；PB 中则要编码 gate 对 Pauli operators 的 conjugation。这里先沿着 CB 把整个 circuit 接起来。

4. Circuit：把局部 Transitions 接起来

4.1 Circuit encoding 和 composition

设 circuit 按时间顺序执行 gates G0,…,Gm−1G_0,\ldots,G_{m-1}。如果 UtU_t 是 GtG_t 的 matrix，那么整个 circuit 的 matrix 是：

UC=Um−1⋯U1U0. U_C=U_{m-1}\cdots U_1U_0.

右边的 U0U_0 最先作用。这里把时间顺序和 matrix multiplication order 分开写，后面比较两个 circuits 时也遵守这个约定。

为各个时刻引入 basis labels 𝐪0,…,𝐪m\mathbf q^0,\ldots,\mathbf q^m，相邻 gates 共享连接处的 variables。先定义不固定 input 的 circuit relation：

FC=⋀t=0m−1FGt(𝐪t,𝐪t+1,𝐮t). F_C=\bigwedge_{t=0}^{m-1} F_{G_t}(\mathbf q^t,\mathbf q^{t+1},\mathbf u^t).

如果 input 是 |0n⟩|0^n\rangle，再加上：

Finit(𝐪0)=⋀i=0n−1¬qi0. F_{\mathrm{init}}(\mathbf q^0)=\bigwedge_{i=0}^{n-1}\neg q_i^0.

这里将 initial condition 与 circuit relation 分开；simulation paper §3.2 的 FCF_C 则已经包含 initial condition。分开后，simulation 可以固定 input，后面的 cyclic encoding 可以让 input labels 保持自由。

一个完整 satisfying assignment 现在描述所有时刻的 basis labels，以及每个 gate 的 auxiliary choices。在 CB 的展开中，它给出一条合法 computational path。它是计算 amplitude 时的一项，不是声称系统在物理上沿着一条 classical trajectory 演化。

对于路径 π=(b0,…,bm)\pi=(b^0,\ldots,b^m)，其中 b0=0nb^0=0^n，它的 contribution 是：

a(π)=∏t=0m−1⟨bt+1|Ut|bt⟩. a(\pi)=\prod_{t=0}^{m-1}\langle b^{t+1}|U_t|b^t\rangle.

到达输出 bb 的 amplitude 来自所有以它为终点的 paths：

αb=⟨b|UC|0n⟩=∑π:0n→ba(π). \alpha_b=\langle b|U_C|0^n\rangle =\sum_{\pi:\,0^n\to b}a(\pi).

每条 path 内乘 transition amplitudes，不同 paths 之间求和。这正好是 WMC 的 sum-of-products structure。因此加上固定 output 的 constraint FbF_b，就得到：

WMC⁡w(Finit∧FC∧Fb)=αb. \operatorname{WMC}_w(F_{\mathrm{init}}\land F_C\land F_b)=\alpha_b.

这个 path-sum 是把 gate composition 展开后的解释，对应 synthesis paper §2.3 的 encoding 与 Lemma 2。这里 αb\alpha_b 专指输出 UC|0n⟩U_C|0^n\rangle 的 amplitude。

从公式到 CNF 时也要保留这些 weighted contributions。仅仅保留 satisfiability 不够：如果一个 path 因为新 auxiliaries 获得多个额外 extensions，普通 model count 就会改变。上面的 Hadamard encoding 让 auxiliaries 由 transition 确定，正是最小的例子。

4.2 Example：两个 Hadamard gates

从 |0⟩|0\rangle 出发连续执行两次 HH。下面把四条 paths 全部列出来，箭头上省略 gate 名称，每一步都是 HH：

Path Product of transition amplitudes
0→0→00\to0\to0 (1/2)(1/2)=1/2(1/\sqrt2)(1/\sqrt2)=1/2
0→1→00\to1\to0 (1/2)(1/2)=1/2(1/\sqrt2)(1/\sqrt2)=1/2
0→0→10\to0\to1 (1/2)(1/2)=1/2(1/\sqrt2)(1/\sqrt2)=1/2
0→1→10\to1\to1 (1/2)(−1/2)=−1/2(1/\sqrt2)(-1/\sqrt2)=-1/2

按终点分别求和：

α0=12+12=1,α1=12−12=0. \alpha_0=\frac12+\frac12=1, \qquad \alpha_1=\frac12-\frac12=0.

于是 H2|0⟩=|0⟩H^2|0\rangle=|0\rangle。到达 00 的 contributions 相长，到达 11 的 contributions 相消。这是直接用 Hadamard matrix 算出的例子，也说明 interference 怎样出现在 weighted satisfying assignments 的加和中。

必须先把到达同一终点的 amplitudes 加起来，再取模平方。若先对每条 path 取模平方再求和，相消的信息就没有了。

5. Computational Basis 和 Pauli Basis

5.1 从 State Vector 到 Density Matrix

CB 的 path-sum 很直观，但一般需要 complex weights。Simulation paper 采用另一种表示：先把 pure state 变成 density matrix，再在 Pauli basis 中展开。

ρ=|ψ⟩⟨ψ|=∑j=04n−1βjPj,Pj∈{I,X,Y,Z}⊗n. \rho=|\psi\rangle\langle\psi| =\sum_{j=0}^{4^n-1}\beta_jP_j, \qquad P_j\in\{I,X,Y,Z\}^{\otimes n}.

为什么这里换成了 density matrix？因为 Pauli strings 是 operators，它们构成 operator space 的 basis；|b⟩|b\rangle 则是 state-vector space 的 basis。两者展开的对象不同。

一个最小的例子是：

|0⟩⟨0|=(1000)=I+Z2. |0\rangle\langle0|= \begin{pmatrix}1&0\\0&0\end{pmatrix} =\frac{I+Z}{2}.

同一个 |0⟩|0\rangle，在 CB 中只有一个 basis component；它的 density matrix 在 PB 中有两个 components，各自 coefficient 为 1/21/2。

由于 ρ\rho 和 PjP_j 都是 Hermitian，Pauli coefficients βj\beta_j 是 real，但可以为负。比如 |−⟩⟨−|=(I−X)/2|-\rangle\langle-|=(I-X)/2。这不要求 Pauli matrices 自身只有 real entries：YY 含有 imaginary entries，real 的是展开系数。（Simulation paper §2.1；synthesis paper §2.1、§2.3。）

Computational Basis (CB) Pauli Basis (PB)
Representation object State vector |ψ⟩|\psi\rangle Density matrix ρ\rho
Basis element |b⟩|b\rangle Pauli string PjP_j
一个时刻的 basis assignment Bit string bb 每个 qubit 上的 Pauli label
完整 circuit assignment 一条 basis path 的贡献 一条 Pauli 展开路径的贡献
按终点汇总后的 weight Amplitude αb\alpha_b Coefficient βj\beta_j
Numerical domain 一般为 complex Real，可以为负

PB 每个 qubit 用两个 bits 编码：(xi,zi)=00,10,11,01(x_i,z_i)=00,10,11,01 分别表示 I,X,Y,ZI,X,Y,Z。这里的 xi,zix_i,z_i 是 Boolean variables，X,Y,ZX,Y,Z 则是 Pauli operators。

还要区分一个 assignment 的 contribution 和最终 coefficient。同一个输出 Pauli string 可能由多条展开路径得到，βj\beta_j 是这些 contributions 求和后的结果；CB 的 αb\alpha_b 也是如此。

5.2 Stabilizers 和 Generalized Stabilizers

如果一个 operator PP 满足：

P|ψ⟩=|ψ⟩, P|\psi\rangle=|\psi\rangle,

就说 PP stabilizes |ψ⟩|\psi\rangle。例如 Z|0⟩=|0⟩Z|0\rangle=|0\rangle。

对于一个 nn-qubit stabilizer state，它的 stabilizer group SψS_\psi 包含 2n2^n 个 commuting Pauli operators，包括可能带负号的 Pauli strings。它的 density operator 可以写成：

|ψ⟩⟨ψ|=12n∑P∈SψP. |\psi\rangle\langle\psi|= \frac1{2^n}\sum_{P\in S_\psi}P.

刚才的 (I+Z)/2(I+Z)/2 就是 S|0⟩={I,Z}S_{|0\rangle}=\{I,Z\} 的情况。Clifford gates 适合这个表示，因为 conjugation P↦UPU†P\mapsto UPU^\dagger 把 Pauli group 映回自身。（Simulation paper §2.2, Eq. 1。）

但加入 non-Clifford TT gate 后，单个 Pauli operator 可以变成 linear combination：

TXT†=X+Y2,TYT†=Y−X2. TXT^\dagger=\frac{X+Y}{\sqrt2}, \qquad TYT^\dagger=\frac{Y-X}{\sqrt2}.

所以普通 Pauli stabilizer group 的形式不足以直接处理这种 evolution。Simulation paper §3.1 的 Definition 2 与 Proposition 1 使用 generalized stabilizer group。一个具体 construction 是：若 |ψ⟩=U|0n⟩|\psi\rangle=U|0^n\rangle，取

Sψ={UPU†:P∈S|0n⟩}. S_\psi=\{UPU^\dagger:P\in S_{|0^n\rangle}\}.

它仍有 2n2^n 个 commuting unitary operators，都以 |ψ⟩|\psi\rangle 为 +1+1 eigenvector，并且上面的 density-operator 求和公式仍然成立。但这些 operators 不一定还是单个 Pauli string；将它们展开，就得到带 real coefficients 的 Pauli sums。

Encoding 进一步把这些 sums 展平，保留每个 weighted Pauli contribution。一个被展开出来的 summand 不必单独 stabilize |ψ⟩|\psi\rangle，任意一堆 weighted strings 也不能直接叫作 stabilizer group。

因此，Pauli basis 是选择怎样表示 operator；stabilizer formalism 则描述一类 state 与 operators 之间的结构。Generalized construction 说明了如何越过 Clifford 的限制。最后交给 simulation model counter 的是 real weights，包括 negative weights，不需要直接处理 complex amplitudes。

6. Strong Simulation：把 Measurement 也编码进去

现在 circuit 已经固定，想知道一个指定 measurement outcome 的 probability。对完整 computational-basis outcome bb，CB 给出：

p(b)=|αb|2. p(b)=|\alpha_b|^2.

在 density-matrix 表示中，若 outcome 对应 projector Π\Pi，则：

p(Π)=Tr⁡(Πρ),ρ=UC|0n⟩⟨0n|UC†. p(\Pi)=\operatorname{Tr}(\Pi\rho), \qquad \rho=U_C|0^n\rangle\langle0^n|U_C^\dagger.

这就是 simulation paper Definition 1 所定义的 strong simulation quantity。Π\Pi 在这里始终表示 measurement projector，PjP_j 始终表示 Pauli string。

6.1 Measurement 的 constraints 和 normalization

先说明 normalization 的放置。前面的 βj\beta_j 是 normalized density matrix 的 coefficients；simulation paper §3.2 的实际 encoding 从 initial stabilizer group 出发，将公共因子 2−n2^{-n} 留在外面。用前面分开的 circuit notation，它表示：

ρ=12n∑ω⊨Finit∧FCW(ω)Pout(ω). \rho=\frac1{2^n} \sum_{\omega\models F_{\mathrm{init}}\land F_C} W(\omega)P_{\mathrm{out}}(\omega).

此处是 PB encoding。Initial condition 让每个 qubit 的 Pauli label 为 II 或 ZZ，初始符号为正；并不是 CB 中将每个 qubit 的 basis bit 固定为 00。

设测量 qubit 集合 MM，k=|M|k=|M|，先考虑这些 qubits 全部得到 00。Projector 在被测 qubits 上是 (I+Z)/2(I+Z)/2，其余位置是 II。由 trace 公式展开，只有以下输出 Pauli strings 有贡献：被测位置为 II 或 ZZ，未测位置为 II。因此可以把选择条件明确写成：

Fmeas=⋀i∈M¬xim∧⋀i∉M(¬xim∧¬zim). F_{\mathrm{meas}}= \bigwedge_{i\in M}\neg x_i^m \ \land\! \bigwedge_{i\notin M}(\neg x_i^m\land\neg z_i^m).

这里未测量位置的 II 条件来自 Tr⁡(X)=Tr⁡(Y)=Tr⁡(Z)=0\operatorname{Tr}(X)=\operatorname{Tr}(Y)=\operatorname{Tr}(Z)=0，不能把这些位置的所有 Pauli labels 都无条件加进去。每个保留下来的 string 满足 Tr⁡(ΠP)=2n−k\operatorname{Tr}(\Pi P)=2^{n-k}；与 density matrix 外面的 2−n2^{-n} 合起来，留下 2−k2^{-k}。

于是，simulation paper §3.4, Proposition 2 的 strong simulation 等式是：

F=Finit∧FC∧Fmeas, F=F_{\mathrm{init}}\land F_C\land F_{\mathrm{meas}},
12kWMC⁡w(F)=⟨0n|UC†ΠUC|0n⟩. \frac1{2^k}\operatorname{WMC}_w(F) =\langle0^n|U_C^\dagger\Pi U_C|0^n\rangle.

这里用 kk 代替原 Proposition 中被测 qubits 数量的 qq，避免与 basis variables 混淆。上面的具体 constraints 是把 trace 条件显式展开后的全零 outcome 情况。其他 bit outcomes 使用 (I−Z)/2(I-Z)/2 的相应符号贡献；probability 的定义与 normalization 不变。

用一个 qubit 检查就很清楚：|0⟩⟨0|=(I+Z)/2|0\rangle\langle0|=(I+Z)/2，两个贡献的 count 是 22，乘 1/21/2 得到 11。执行 HH 后，density matrix 为 (I+X)/2(I+X)/2，测得 00 时只有 II 项保留下来，count 是 11，probability 是 1/21/2。

论文还给出一个 single-qubit 的等价做法：只选择输出 Pauli string ZiZ_i，算出 si=Tr⁡(Ziρ)s_i=\operatorname{Tr}(Z_i\rho)，再用：

pi(0)=1+si2. p_i(0)=\frac{1+s_i}{2}.

它对应 §3.4 的 Eq. 6–7。这个只选 ZiZ_i 的 count 算的是 expectation，不能直接叫作 probability，也不能和同时保留 II 项的 measurement encoding 混用。

6.2 从 Reduction 到 Simulator

逻辑上可以给每个时刻画一组 state variables，但实现时没有必要为不变的 qubits 反复分配新 variables。Simulation paper §3.2 复用不变的 labels，每个局部 gate 只增加常数个 variables 和 constraints；initial condition 需要 O(n)O(n)，于是 mm 个 gates 的 encoding size 是 O(n+m)O(n+m)。这是 formula size 的结论，不是 WMC 求解时间为线性。

这一点让 reduction 可以实际落地。论文的 QCMC 读取 QASM，构造 weighted CNF，再交给支持 negative weights 的 GPMC。§4 的实验比较了 QuiZX 和 Quasimodo：随机 circuits 与部分带 rotation gates 的 benchmarks 展示了 WMC 的优势，但 Grover、quantum walk 等 structured circuits 中也有其他方法更快的情况。

所以这里得到的是一种可执行的 universal-circuit strong simulation 方法：用 generalized stabilizer / Pauli representation 避开直接的 complex weights，用线性大小的 encoding 把任务交给已有 counter。不同 circuit structure 下的求解代价仍然不同。

7. 从 Simulation 到 Verification

Simulation 问的是：这个 circuit 会产生什么 behaviour？Verification 则进一步问：这个 behaviour 是否满足 specification？

一旦有 circuit relation，就可以把适用的 input conditions 与 output conditions 接在两端。例如对固定 input，算出指定 outcome 的 probability 后，再判断它是否满足要求。这是前面 simulation query 的直接用法；更一般的 specifications 还需要各自的 semantics 和 encoding。

这里有一个容易忽略的区别：某条 Boolean path 存在，不代表对应 measurement outcome 有非零 probability。两个 HH 的例子中，到达 11 的 paths 都合法，amplitude 却为 00。因此这类 quantum property 不能只看 SAT/UNSAT，还要看 weighted sum。

这一节只是由 representation 得到的 verification 视角。两篇论文在本文中支持的具体任务是 strong simulation、unitary equivalence 和 synthesis；不能由此直接推出一个 general quantum verification framework。接下来只看其中定义明确的 equivalence problem。

8. Equivalence：比较两个 Circuits

8.1 Global phase 和 approximate equivalence

设 C1C_1 是 target，C2C_2 是另一个 circuit。Exact equivalence 比较的是所有 inputs 上的 unitary behaviour，而不是只比较 |0n⟩|0^n\rangle 这一个 input。

按 synthesis paper Definition 3，exact equivalence 允许 global phase：

UC2≡UC1⇔UC2=λUC1,|λ|=1. U_{C_2}\equiv U_{C_1} \quad\Longleftrightarrow\quad U_{C_2}=\lambda U_{C_1},\qquad |\lambda|=1.

沿用该论文 §4 的 composition order，定义：

D=UC2UC1†. D=U_{C_2}U_{C_1}^\dagger.

也就是先作用 target inverse，再作用 C2C_2。于是：

UC2≡UC1⇔D≡I⊗n. U_{C_2}\equiv U_{C_1} \quad\Longleftrightarrow\quad D\equiv I^{\otimes n}.

Approximate equivalence 则需要一个比较标准。论文使用 Jamiołkowski fidelity：把 unitary UU 作用到 maximally entangled state 的一半，得到对应的 state，再比较这些 states 的 overlap。

|Ψn⟩=12n∑b|b⟩⊗|b⟩,|ϕU⟩=(U⊗I⊗n)|Ψn⟩, |\Psi_n\rangle=\frac1{\sqrt{2^n}}\sum_b|b\rangle\otimes|b\rangle, \qquad |\phi_U\rangle=(U\otimes I^{\otimes n})|\Psi_n\rangle,
Fid⁡J(U,V)=|⟨ϕU|ϕV⟩|2. \operatorname{Fid}_J(U,V)=|\langle\phi_U|\phi_V\rangle|^2.

Definition 3 规定：

U≃εV⇔Fid⁡J(U,V)≥1−ε. U\simeq_\varepsilon V \quad\Longleftrightarrow\quad \operatorname{Fid}_J(U,V)\geq1-\varepsilon.

ε=0\varepsilon=0 时 fidelity 为 11，恰好对应 global phase 意义下的 exact equivalence。后面所有 approximate synthesis 都使用这个 criterion。

8.2 Cyclic encoding

前面的 simulation 固定 input。现在要比较整个 operator，就让 input basis labels 自由，并要求 output label 与 input label 相同：

Fcyc(D)=FD(𝐪,𝐪′)∧FI(𝐪,𝐪′). F_{\mathrm{cyc}}(D)=F_D(\mathbf q,\mathbf q')\land F_I(\mathbf q,\mathbf q').

CB 中，FIF_I 是每个 qi↔qi′q_i\leftrightarrow q_i' 的合取；PB 中，则对每个 qubit 同时要求 xi↔xi′x_i\leftrightarrow x_i' 和 zi↔zi′z_i\leftrightarrow z_i'。Intermediate 和 auxiliary variables 仍然参与 model counting。

这个 input/output equality 的作用可以直接在 CB 中看出来：对每个 input bb，只累加回到同一个 bb 的 amplitude，然后再对所有 bb 求和。因此：

cCB(D):=WMC⁡w(FcycCB(D))=∑b⟨b|D|b⟩=Tr⁡(D). c_{\mathrm{CB}}(D) :=\operatorname{WMC}_w(F_{\mathrm{cyc}}^{\mathrm{CB}}(D)) =\sum_b\langle b|D|b\rangle =\operatorname{Tr}(D).

所以 cyclic count 是一个 trace，并不是只问“有没有一条路径回到原点”。对于 D=λI⊗nD=\lambda I^{\otimes n}，它等于 2nλ2^n\lambda，global phase 仍在 count 中。

PB 的情况类似，但被比较的是 conjugation P↦DPD†P\mapsto DPD^\dagger。令 RD(j,j)R_D(j,j) 表示 DPjD†DP_jD^\dagger 中 PjP_j 的 coefficient，cyclic count 就是：

cPB(D):=WMC⁡w(FcycPB(D))=∑j=04n−1RD(j,j). c_{\mathrm{PB}}(D) :=\operatorname{WMC}_w(F_{\mathrm{cyc}}^{\mathrm{PB}}(D)) =\sum_{j=0}^{4^n-1}R_D(j,j).

这里自由取遍的是 operator basis labels，不是一个 normalized initial density matrix，所以不加入 simulation 中的 FinitF_{\mathrm{init}} 或它的 normalization。

Synthesis paper Theorem 5 给出 exact criterion：

D≡I⊗n⇔|cCB(D)|=2n⇔cPB(D)=4n. D\equiv I^{\otimes n} \quad\Longleftrightarrow\quad |c_{\mathrm{CB}}(D)|=2^n \quad\Longleftrightarrow\quad c_{\mathrm{PB}}(D)=4^n.

它还给出 PB 的 linear-cyclic variant：只让初始 Pauli label 取 {Xi,Zi:i∈[n]}\{X_i,Z_i:i\in[n]\} 中的 2n2n 个元素，再做同样的 cyclic constraint。这个 count 达到 2n2n 当且仅当 exact equivalence 成立。

论文将这两种单次 WMC call 的 construction 与之前需要 2n2n 次 calls 的 linear encoding 联系起来。这里采用的是该论文 Theorem 5 与 Appendix A.1 的结果；linear-cyclic count 只是 exact criterion，不能直接当作下面的 Jamiołkowski fidelity。

8.3 从 Cyclic Count 到 Fidelity

真正把 exact 与 approximate 连起来的是 synthesis paper Theorem 10。保持 D=UC2UC1†D=U_{C_2}U_{C_1}^\dagger，有：

Fid⁡J(UC1,UC2)=|Tr⁡(D)|24n=|cCB(D)|24n=cPB(D)4n. \operatorname{Fid}_J(U_{C_1},U_{C_2}) =\frac{|\operatorname{Tr}(D)|^2}{4^n} =\frac{|c_{\mathrm{CB}}(D)|^2}{4^n} =\frac{c_{\mathrm{PB}}(D)}{4^n}.

Theorem 10 的陈述使用 U†VU^\dagger V；这里沿用 §4 的 candidate-times-target-inverse，因为 Tr⁡(U†V)=Tr⁡(VU†)\operatorname{Tr}(U^\dagger V)=\operatorname{Tr}(VU^\dagger)。这就是将定理用于同一个 composition order 的理由。

CB count 可能是 complex，需要取模平方；PB count 已经是 4n4^n 倍的 fidelity，只需 normalization。不能把两种 count 的后处理混用。

于是 exact checking 和 approximate checking 都可以用 cyclic encoding，只是最后判断 count 是否对应 fidelity 11，或者至少 1−ε1-\varepsilon。这一结果也准备好了 synthesis 所需要的评价函数。

9. Synthesis：把 Circuit 本身变成 Boolean Choices

到这里，circuit 一直是给定的。Synthesis 把问题反过来：给定想实现的 behaviour，寻找实现它的 circuit。

按 synthesis paper Problem 4，输入是 target circuit C1C_1 或其 unitary、有限 target gate set 𝒢\mathcal G，以及 approximation parameter ε\varepsilon。目标是在 𝒢\mathcal G 中找 depth 最小的 C2C_2，满足：

UC2≃εUC1. U_{C_2}\simeq_\varepsilon U_{C_1}.

先固定一个 candidate depth dd。与前面按单个 gate 编号不同，这里的 tt 表示 parallel gate layer：同一层中，一个 qubit 只能参与一个 gate。

为每个单 qubit gate choice 引入：

pG,i,t=1⇔layer t 在 qubit i 上选择 G. p_{G,i,t}=1 \quad\Longleftrightarrow\quad \text{layer }t\text{ 在 qubit }i\text{ 上选择 }G.

例如一个 qubit、可选 gates 为 {I,H,T}\{I,H,T\} 时，pI,0,t,pH,0,t,pT,0,tp_{I,0,t},p_{H,0,t},p_{T,0,t} 中恰好一个为真。选择 HH 时，激活的就是之前的 FHF_H：

pH,0,t⇒FH(qt,qt+1,𝐮Ht). p_{H,0,t}\Rightarrow F_H(q^t,q^{t+1},\mathbf u_H^t).

Multi-qubit gates 使用相应的 selection variables，例如 pCX,i,j,tp_{CX,i,j,t}，其中 ii 是 control、jj 是 target。Exactly-one constraints 必须对一个 qubit 上所有可能占用它的 gates 一起约束，包括它作为 control 或 target 的 choices。这样才能排除同一层中相互重叠的 gates。Identity 也作为一个 choice，让某些 qubits 可以空闲。

这些是 synthesis paper §4, Eq. 7–11 的 layer encoding。固定所有 selection variables，就确定了每层的合法 gates，因而确定一个 candidate circuit C2C_2。

这里沿用的 weighted gate encoding 还必须保证：未被选择的 gate auxiliaries 不会额外贡献 weights 或重复 models。上面的 implication 是说明 gate selection 的结构；把它实现为完整 weighted CNF 时，这些 bookkeeping 同样属于语义的一部分。

10. 为什么是 Maximum Weighted Model Counting？

把 variables 分成两组。为避免与 Pauli operators X,YX,Y 混淆，用花体表示变量集合：

𝒳={gate-selection variables},𝒴={basis/path/auxiliary variables}. \mathcal X=\{\text{gate-selection variables}\}, \qquad \mathcal Y=\{\text{basis/path/auxiliary variables}\}.

先编码固定的 target inverse，再接上 dd 个待选择的 layers，最后要求首尾 basis labels 相同。采用 PB cyclic encoding，可把 synthesis formula 写成：

Fsyn,d(𝒳,𝒴)=FC1†(𝐪in,𝐪0)∧⋀t=0d−1Flayer,𝒢(𝐪t,𝐪t+1,𝐩t)∧FI(𝐪in,𝐪d). F_{\mathrm{syn},d}(\mathcal X,\mathcal Y)= F_{C_1^\dagger}(\mathbf q_{\mathrm{in}},\mathbf q^0) \land\bigwedge_{t=0}^{d-1} F_{\mathrm{layer},\mathcal G}(\mathbf q^t,\mathbf q^{t+1},\mathbf p^t) \land F_I(\mathbf q_{\mathrm{in}},\mathbf q^d).

这对应 synthesis paper Eq. 12。固定一个 gate assignment ξ\xi 后，candidate C2(ξ)C_2(\xi) 就固定了。内部 WMC 负责评价它：

Sd(ξ)=∑η:(ξ,η)⊨Fsyn,dW(ξ,η)=4nFid⁡J(UC1,UC2(ξ)). S_d(\xi)= \sum_{\eta:\,(\xi,\eta)\models F_{\mathrm{syn},d}} W(\xi,\eta) =4^n\operatorname{Fid}_J(U_{C_1},U_{C_2(\xi)}).

Gate-selection variables 本身的 weights 取 11。内层对 𝒴\mathcal Y 求和；外层则要选择一个最好的 ξ\xi。用 𝒜d\mathcal A_d 表示满足 valid-layer constraints 的 gate assignments，根据论文 §2.2 的 Definition 1，Maximum Weighted Model Counting 在这里就是：

ξ⋆∈arg maxξ∈𝒜dSd(ξ),sd⋆=maxξ∈𝒜d∑η:(ξ,η)⊨Fsyn,dW(ξ,η). \xi^\star\in\operatorname*{arg\,max}_{\xi\in\mathcal A_d}S_d(\xi), \qquad s_d^\star=\max_{\xi\in\mathcal A_d} \sum_{\eta:\,(\xi,\eta)\models F_{\mathrm{syn},d}}W(\xi,\eta).

这就是 max⁡𝒳∑𝒴\max_{\mathcal X}\sum_{\mathcal Y} 的结构。Exactly-one constraints 限定合法 candidates，counter 返回一个最优 gate assignment 及其 count。

所以 WMC evaluates a fixed circuit；MaxWMC searches over circuits while evaluating each one。外层不能也变成 sum，否则只是把不同 circuits 的 scores 混在一起；内层也不能变成 max，否则只留下某条 path，丢掉 interference。

这里选择 PB cyclic 作为主线，是因为它的完整 inner count 是 real fidelity score。即使中间 contributions 有负号，合法 candidate 的 Sd(ξ)S_d(\xi) 仍在 [0,4n][0,4^n]。CB 的 cyclic count 则可能为 complex，目标应是其模平方对应的 fidelity，不能把“最大 complex number”当成普通实数 MWMC 的定义。

11. Exact、Approximate 和 Depth-optimal Synthesis

固定 depth 的 MaxWMC 只解决一件事：在这个 depth 内，哪个 candidate 的 fidelity 最高？Depth optimality 还需要外层逐步增大 dd。

对于上面的 PB cyclic encoding，exact synthesis 的判断是：

sd⋆=4n. s_d^\star=4^n.

这是 synthesis paper Proposition 8 的 PB cyclic 情况。若只做 exact synthesis，也可以使用 PB linear-cyclic encoding，把对应 count 的目标改成 2n2n。

Approximate synthesis 则按照 Definition 3 与 Theorem 10 检查：

sd⋆4n≥1−ε. \frac{s_d^\star}{4^n}\geq1-\varepsilon.

从 d=0d=0 的 empty circuit 开始，然后尝试 d=1,2,…d=1,2,\ldots。当某个 depth 首次达到要求时，从 ξ⋆\xi^\star 读出 gates，就得到目标 gate set 下的 minimum-depth circuit。这个结论要求之前更小的 depths 已被完整排除；某一层搜索 timeout，并不能证明该层没有解。ε=0\varepsilon=0 时还要求 target 能被所选 gate set 精确实现，否则不断增加 depth 不保证终止。

例如用 {I,H,T}\{I,H,T\} 合成单 qubit target SS。Depth 00 或 11 没有 exact solution；depth 22 可以在两层都选择 TT，得到 T2=ST^2=S。这是 synthesis paper Example 6 与 Example 9 中的 gate identity。它展示的是 exact minimum-depth search，不需要把每层的 candidate scores 都列出来。

如果允许 ε>0\varepsilon>0，一个更浅的 candidate 达到 fidelity threshold 就可以停止。因而这有两层不同的优化：fixed depth 内比较 fidelity；across depths 找第一个满足 criterion 的 depth。Maximum fidelity 和 minimum depth 不是同一个 objective。

关于原文的一个记号细节：所用 synthesis paper v2 的 Proposition 11 中，CB 阈值写成 2−n|c|>1−ε2^{-n}|c|>1-\varepsilon，与 Definition 3、Theorem 10 的 squared-fidelity 定义不一致。本文统一使用后两者，因此 CB 的 threshold 应写为 4−n|c|2≥1−ε4^{-n}|c|^2\geq1-\varepsilon，PB 则是 4−nc≥1−ε4^{-n}c\geq1-\varepsilon。上面的算法解释对应 Proposition 11 的逐层搜索思路，数值判据按这个统一的 fidelity 定义计算。

12. 同一个 Representation，以及它的限制

从 state 到 synthesis，变化的是哪些 choices 已经固定，以及最后对哪些 variables 求和或优化：

Task 固定什么 计算或搜索什么
Simulation Circuit、input、measurement query 与 outcome 对应的 weighted sum
Verification 视角 Circuit 与 specification 所需 quantum quantity 是否满足条件
Equivalence 两个 circuits Composed circuit 的 cyclic count / fidelity
Synthesis Target、gate set、当前 depth 使 inner count 最优的 gate assignment

Gate relation 仍然承载局部 semantics，composition 仍然把局部贡献乘起来，WMC 仍然把合法贡献加起来。Synthesis 多出来的，就是 circuit structure 本身也可以由 Boolean variables 决定。

Synthesis paper §7 将方法实现为 Quokka#-syn，并扩展 d4Max 来支持 PB 的 negative weights 和 CB 的 complex weights。实验展示了 exact 与 approximate synthesis 的可行性，也显示 qubit 数和 depth 增长后，求解很快变得困难。与其他 synthesis 工具的比较还受到平台、gate set 和 benchmark 差异的限制，不能据此给出普遍的性能排序。

Negative weights 也会影响 solver 内部的推理。论文 §7.1 说明，原 d4Max 的一些 upper-bound pruning 和 intermediate approximation 优化在扩展后被关闭，当前实现因此失去了部分效率。一个紧凑的 encoding，并不会自动带来一个容易求解的 optimization problem。

论文 §8 提出的改进方向包括：跨 depth 的 incremental solving，更充分利用 CNF 中的 XOR structure，以及 symmetry 处理。T-count optimization 也被列为后续目标；本文讨论的 depth-optimality 本身并不保证 T-count 最小。

到这里，可以把接下来的问题放在 solver 一侧：这些 weighted formulas 已经保留了所需的 quantum semantics，怎样更有效地计算它们？
